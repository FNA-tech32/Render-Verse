## 💻 Local Development & Setup

This project is built with zero build step dependencies and runs natively in any modern web browser.

### Option 1: Python HTTP Server (Recommended)
Open a terminal in the project directory and run:
```bash
# Python 3
python -m http.server 8000
```
Open your browser at `http://localhost:8000`.

### Option 2: Node.js (npx serve)
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click on `index.html` inside VS Code and choose **"Open with Live Server"**.

## 🚢 Deployment

The static multi-page website can be deployed to any modern static hosting service:
- **GitHub Pages:** Go to repository **Settings > Pages > Branch: `main` > `/ (root)` > Save**.
- **Vercel / Cloudflare Pages / Netlify:** Import the repository directly; no build command required, publish directory is `.`.
